# emotionstory（感情に合った短編ジェネレーター）

いまの感情を選ぶと、それに合った短編（600〜1000字程度）をその場で生成して表示する、単一ファイル Flask の小さな Web ツールです。データベースは使いません。

## これは何をするもの？

- 感情を6種から選ぶ：うれしい／かなしい／つかれた／わくわく／おだやか／さみしい
- 任意でキーワードを1つ入れると、本文の中に自然に織り込まれます
- 生成された短編にはタイトルが付き、「再生成」ボタンで同じ入力のまま別の話を出すこともできます
- 同じ入力でも、毎回少し違う話になります

## 仕組み（テンプレート方式）

外部の AI API は使いません。ルールベース／テンプレート方式です。

- 感情ごとに「導入・中盤・結び」の断片プール（各7個）を用意
- さらに「場所・小物・時間帯」の要素プールと、情景の一文をランダムに組み合わせ
- 導入 → 情景 → 中盤 →（キーワードの一節）→ 中盤 → 結び の順に接続し、本文が600〜1000字に収まるよう調整
- キーワードの一節は専用の文型プールから選ばれ、本文に織り込まれます

組み合わせの総数が多いため、同じ感情・同じキーワードでも毎回違う話になります。

## 起動方法

```bash
pip install -r requirements.txt
python app.py
```

起動したらブラウザで http://127.0.0.1:5000 を開いてください。

## テスト

```bash
python -m unittest discover -s tests
```

## デプロイ（Render）

`render.yaml` を使って Web Service（Free）としてデプロイできます。起動コマンドは `gunicorn app:app`、ヘルスチェックは `/healthz` です。

## 構成

- `app.py` … 本体（単一ファイル）
- `tests/test_app.py` … unittest
- `requirements.txt` … Flask と gunicorn のみ
